# EROPEL

A lightweight static site for EROPEL, structured as root-level page folders for GitHub Pages.

## Local preview

Run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Replacing artwork

Placeholder art lives in `assets/art/`. Replace each file with a photographed artwork and update its image path, intrinsic dimensions, alt text, and recovery record in `objects/`.
